# Factorio Mod Manager 3.0.0

Major desktop release.

- Single-file Windows EXE; no Python/BAT launcher required for end users.
- Original custom midnight-blue app icon.
- Customizable sidebar/menu, main background and accent colors.
- Full Mod Portal-style detail page when a Search result is opened.
- Information / Downloads / Dependencies / Changelog / Metrics views.
- EXE-aware GitHub Releases updater with automatic replacement + restart.
